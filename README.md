# CryptoWallet

Навчальний проєкт мікросервісної платформи для керування криптовалютними гаманцями в тестовій мережі **Sepolia Ethereum**. Проєкт орієнтований на знайомство з мікросервісною архітектурою, асинхронним програмуванням та роботою з криптовалютами.

## 🧩 Функціонал

**Гаманці**
- Створення нового ETH-гаманця (генерація приватного ключа та адреси)
- Імпорт існуючого гаманця за приватним ключем
- Перегляд балансу всіх гаманців користувача з автооновленням раз на хвилину
- Миттєве оновлення балансу конкретного гаманця при вхідній/вихідній транзакції (через WebSocket-подію)
- Відправка коштів на інший гаманець зі статусами транзакцій (`PENDING` → підтверджено)
- Перегляд історії транзакцій гаманця в реальному часі

**Автентифікація**
- Реєстрація та логін з видачею JWT access-токена
- Валідація пароля (мінімум 8 символів, великі/малі літери, цифра)
- Система permissions окремою таблицею в БД (без зберігання прав у самому JWT)

**Чат**
- Загальний чат усіх власників гаманців з історією повідомлень
- Підвантаження останніх 10 повідомлень при вході, live-оновлення через WebSocket

**Торгова платформа (iBay)**
- Створення лотів та подання заявок на них
- Статусна модель заявки: `НОВИЙ → ОПЛАЧЕНО/ПРОВАЛЕНО → ДОСТАВКА → ЗАВЕРШЕНО/ПОВЕРНЕНО`
- Фонові обробники, що періодично змінюють статус заявок

## 🛠 Технологічний стек

**Backend**
- Python, FastAPI
- TaskIQ — фонові задачі
- FastStream — робота з чергами повідомлень (мікросервісна взаємодія)
- PyJWT — авторизація
- python-socketio — WebSockets
- boto3, web3 — робота з S3-сховищем та Ethereum

**Бази даних**
- PostgreSQL, MongoDB

**Frontend**
- Svelte 4 + django-inertia + Vuexy theme

**Інфраструктура**
- Docker, Docker Compose / Easypanel
- Deploy: DigitalOcean (DO Postgres, DO Spaces)
- pre-commit, Poetry

## 🏗 Архітектура

Проєкт побудований за принципами **Clean Architecture** з розбиттям на мікросервіси (окремий API-сервіс і окремий сервіс для WebSocket-подій), сервісним шаром для роботи з БД та rate-limiting на чутливих ендпоінтах (реєстрація, авторизація).
